# Skydio Problem Set

Skydio Problem Set - LeetCode-style live-coding practice for Skydio SWE phone screens

Focus: arrays, hash tables, strings, heaps, math, BFS/DFS, binary search, greedy, and design-style data structures.

1. Insert Delete GetRandom O(1) - Medium
1. Rotting Oranges - Medium
1. Add Two Numbers - Medium
1. Design Tic-Tac-Toe - Medium

1. 3Sum - Medium

1. Ransom Note - Easy
1. Check if One String Swap Can Make Strings Equal - Easy
1. Design an Ordered Stream - Easy
1. Fraction to Recurring Decimal - Medium
