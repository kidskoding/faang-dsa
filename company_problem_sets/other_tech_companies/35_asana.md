# Asana

Asana - Major LeetCode-style problems to drill for Asana SWE interviews

Focus: task graphs, topological ordering, intervals, strings, design data structures, heaps, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Asana-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Asana-style live coding tends to reward.
