# Discord

Discord - Major LeetCode-style problems to drill for Discord SWE interviews

Focus: messaging-style design, rate limits, strings, heaps, graphs, trees, intervals, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Discord-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Discord-style live coding tends to reward.
