# Snap Problem Set

Snap Problem Set - Major LeetCode-style problems to drill for Snap SWE interviews

Focus: arrays, heaps, sliding windows, grids, graph traversal, backtracking, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Snap-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Snap-style live coding tends to reward.
