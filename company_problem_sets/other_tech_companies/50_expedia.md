# Expedia Problem Set

Expedia Problem Set - Major LeetCode-style problems to drill for Expedia SWE interviews

Focus: routing graphs, itinerary reconstruction, intervals, heaps, arrays, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Expedia-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Expedia-style live coding tends to reward.
