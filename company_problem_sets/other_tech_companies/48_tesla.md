# Tesla

Tesla - Major LeetCode-style problems to drill for Tesla SWE interviews

Focus: graph search, grid pathfinding, binary search, heaps, greedy scheduling, intervals, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Tesla-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Tesla-style live coding tends to reward.
