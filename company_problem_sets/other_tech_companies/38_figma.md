# Figma

Figma - Major LeetCode-style problems to drill for Figma SWE interviews

Focus: 2D arrays, geometry-adjacent grids, collaboration-style design, graphs, intervals, tries, trees, and string parsing.

These are not guaranteed exact interview questions. Treat this as the high-signal Figma-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Figma-style live coding tends to reward.
