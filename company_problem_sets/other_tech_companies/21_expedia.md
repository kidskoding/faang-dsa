# Expedia Group

Expedia Group - High-signal LeetCode problems for Expedia SWE intern/new-grad interviews. Curated down from the broader reported set (source: codejeet.com/company/expedia) to the problems that cover Expedia's core live-coding techniques.

Focus: mostly medium. Heavy on binary-search-on-answer, monotonic stacks, heaps, string manipulation, BFS/graphs, trees/BST, sliding window, and intervals. Travel-domain framing (flights, itineraries, capacity) is common but the underlying patterns are standard.

These are not guaranteed exact interview questions. If you can solve these cleanly under time pressure, you cover the main techniques Expedia live coding tends to reward.
