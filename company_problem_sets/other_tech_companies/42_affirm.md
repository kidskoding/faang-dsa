# Affirm

Affirm - Major LeetCode-style problems to drill for Affirm SWE interviews

Focus: DP, arrays, prefix sums, financial-style state transitions, intervals, graphs, heaps, and data-structure design.

These are not guaranteed exact interview questions. Treat this as the high-signal Affirm-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Affirm-style live coding tends to reward.
