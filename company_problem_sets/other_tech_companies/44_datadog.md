# Datadog Problem Set

Datadog Problem Set - Major LeetCode-style problems to drill for Datadog SWE interviews

Focus: logs, streams, rate limits, sliding windows, heaps, graph connectivity, intervals, and design data structures.

These are not guaranteed exact interview questions. Treat this as the high-signal Datadog-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Datadog-style live coding tends to reward.
