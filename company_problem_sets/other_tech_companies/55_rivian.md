# Rivian Problem Set

Rivian Problem Set - Major LeetCode-style problems to drill for Rivian SWE interviews

Focus: graph pathfinding, grids, heaps, binary search, intervals, greedy scheduling, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Rivian-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Rivian-style live coding tends to reward.
