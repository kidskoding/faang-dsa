# Plaid

Plaid - Major LeetCode-style problems to drill for Plaid SWE interviews

Focus: accounts-style graph grouping, hash maps, intervals, string processing, BFS/DFS, heaps, and stateful data structures.

These are not guaranteed exact interview questions. Treat this as the high-signal Plaid-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Plaid-style live coding tends to reward.
