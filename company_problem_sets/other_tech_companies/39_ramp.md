# Ramp

Ramp - Major LeetCode-style problems to drill for Ramp SWE interviews

Focus: stateful data structures, hash maps, intervals, prefix sums, graphs, heaps, and clean API-style implementation.

These are not guaranteed exact interview questions. Treat this as the high-signal Ramp-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Ramp-style live coding tends to reward.
