# Brex Problem Set

Brex Problem Set - Major LeetCode-style problems to drill for Brex SWE interviews

Focus: financial-state modeling, hash maps, intervals, graph search, heaps, prefix sums, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Brex-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Brex-style live coding tends to reward.
