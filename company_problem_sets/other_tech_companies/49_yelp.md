# Yelp Problem Set

Yelp Problem Set - Major LeetCode-style problems to drill for Yelp SWE interviews

Focus: search/ranking, heaps, strings, graphs, intervals, tries, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Yelp-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Yelp-style live coding tends to reward.
