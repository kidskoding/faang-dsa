# Cisco

Cisco - Major LeetCode-style problems to drill for Cisco SWE interviews

Focus: network graphs, BFS/DFS, shortest paths, intervals, heaps, strings, trees, and design data structures.

These are not guaranteed exact interview questions. Treat this as the high-signal Cisco-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Cisco-style live coding tends to reward.
