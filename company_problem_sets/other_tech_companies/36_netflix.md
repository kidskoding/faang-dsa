# Netflix

Netflix - Major LeetCode-style problems to drill for Netflix SWE interviews

Focus: caching, streams, heaps, intervals, graphs, string processing, trees, and DP.

These are not guaranteed exact interview questions. Treat this as the high-signal Netflix-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Netflix-style live coding tends to reward.
