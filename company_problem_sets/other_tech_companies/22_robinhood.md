# Robinhood

Robinhood - Major LeetCode-style problems to drill for Robinhood SWE interviews

Focus: arrays, hash maps, design data structures, heaps, graphs, intervals, trees, DP, and clean state modeling.

These are not guaranteed exact interview questions. Treat this as the high-signal Robinhood-style drill set: if you can solve these cleanly under time pressure, you are covering the main techniques Robinhood-style live coding tends to reward.
