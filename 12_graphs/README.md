# Module 12: Graphs

## Goal

Learn graph representation, traversal, shortest paths, ordering, and grid graph patterns.

## Lessons

- Adjacency lists and matrices
- BFS
- DFS
- Cycle detection
- Matrix / grid traversal
- Multi-source BFS
- Topological sort
- Dijkstra
- Bellman-Ford
- Floyd-Warshall
- Minimum spanning trees
