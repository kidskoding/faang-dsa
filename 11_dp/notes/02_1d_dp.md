# 1D DP

## Pattern

Use one index as the state, usually representing the best answer up to position i.

## Intuition

The current answer depends on earlier positions.

## How It Works

Common for climbing stairs, house robber, decoding, and stock variants.

## Template

```text
dp[0] = base
for i in range(1, n):
    dp[i] = transition(dp[i-1], dp[i-2], ...)
```

## Example

House robber: `dp[i] = max(skip house i, rob house i)`.

## Complexity

```text
Time: O(n)
Space: O(n), often optimizable to O(1)
```

## Pitfalls

- Wrong meaning for `dp[i]`.
- Off-by-one base cases.
- Optimizing space before the transition is correct.

## Interview Checklist

Before coding, make sure you can answer:

```text
What does dp[i] mean in one sentence — best answer up to i, or best answer ending exactly at i?
Which earlier indices does dp[i] depend on, and how far back (i-1, i-2, or all j < i)?
What are dp[0] and dp[1], and do they need separate handling from the general transition?
Is the final answer dp[n-1], or the max/sum over the whole dp array?
Can this be space-optimized to O(1) by keeping only the last one or two values?
```
