# 1D DP

## Pattern

Use one index as the state, usually representing the best answer up to position i.

## Intuition

The current answer depends on earlier positions.

## How It Works

Common for climbing stairs, house robber, decoding, and stock variants.

## Template

```text
dp[0] = base
for i in range(1, n):
    dp[i] = transition(dp[i-1], dp[i-2], ...)
```

## Example

House robber: `dp[i] = max(skip house i, rob house i)`.

## Complexity

```text
Time: O(n)
Space: O(n), often optimizable to O(1)
```

## Pitfalls

- Wrong meaning for `dp[i]`.
- Off-by-one base cases.
- Optimizing space before the transition is correct.

## Interview Checklist

Before coding, make sure you can answer:

```text
What pattern is this?
What state or invariant am I maintaining?
What is the base case or initialization?
When do I update the answer?
Why is the movement/transition valid?
What is the time and space complexity?
```
