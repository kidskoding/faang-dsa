# Module 01: Arrays And Hashing

## Goal

Learn array-backed storage, hash-map/hash-set lookup, frequency maps, grouping, and prefix-style state.

## Lessons

- Dynamic arrays
- Hashing techniques
- Prefix / suffix sums
- Kadane's algorithm
- Hash table implementation
- Collision handling
- Bloom filters
